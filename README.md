# Selavu.Ai - Personal Expense Tracker 💰

Selavu.Ai is a modern, feature-rich web application designed for tracking personal expenses and managing personal finances. Built using Java Servlet technology and rendering JSP pages with a responsive, premium glassmorphism user interface.

It features an embedded **H2 Database Engine** running in Oracle compatibility mode. The database, user accounts, and expense tables are automatically initialized on the first run, requiring zero database installation or configuration.

---

## 📋 Features

### 🔐 Secure User Authentication
* **Sign Up**: Register user account with unique username, email, and password.
* **Sign In**: Secure session-based authentication to access personal financial data.
* **Logout**: Quick session clearing.

### 📊 Real-time Dashboard
* **Financial Overview**: View total spending, today's spending, and total categories used.
* **Interactive Charts**: Interactive category breakdowns powered by Chart.js.
* **Transaction Feed**: Live feed of the latest expense transactions.

### 💰 Expense Tracking
* **Add Expense**: Record new expenses with name, quantity, category, amount, and date.
* **Predefined Categories**: Organize expenses into categories (Food, Transport, Shopping, Entertainment, etc.).

### 📑 Financial Reporting
* **Detailed Reports**: A full transaction history table showing date, item name, quantity, category, and amount.
* **Monthly Category Breakdown**: Visual table of spending aggregate by category grouped by month (e.g., `Jan-2026`).

## 🏗️ Architecture & Project Structure

The project uses a standard Model-View-Controller (MVC) architecture:
* **Model (POJO)**: `RegData.java`
* **DAO / Database transaction layer**: `DBTransaction.java`
* **Controller Servlet**: `SelavuServlet.java`
* **Utility Connection Manager**: `DBCon.java`
* **Views**: JSP pages and HTML templates with Vanilla CSS/JS.

```
Selavu/
├── src/
│   └── main/
│       ├── java/
│       │   └── Money/
│       │       ├── DBCon.java           # Central database connection & auto-table setup
│       │       ├── DBTransaction.java   # Data Access Objects (DAO)
│       │       ├── RegData.java         # User POJO model
│       │       └── SelavuServlet.java   # HTTP Request Handler (Register & Login)

│           ├── META-INF/

│           │   ├── classes/             # Compiled Java classes
│           │   ├── lib/                 # H2 Database Jar & Oracle JDBC Jar
│           │   └── web.xml              # Servlet mapping configuration

```

## 🚀 Setup & Installation (Run Locally)

### Prerequisites
* **Java Development Kit (JDK)**: JDK 11 or higher (Java 17+ recommended).
* **Servlet Container**: Apache Tomcat 10.1.x (supports Jakarta Servlet 6.0 specification).

### Local Execution Instructions

1. **Compile Java Files**:
   Compile the source code using the JDK and direct the compilation outputs into the webapp classes folder.
   ```powershell
   # Compile with Tomcat API jar in classpath
   javac -cp "path/to/tomcat-10.1/lib/servlet-api.jar" -d "Selavu/src/main/webapp/WEB-INF/classes" Selavu/src/main/java/Money/*.java
   ```

2. **Deploy to Tomcat**:
   Copy the contents of `Selavu/src/main/webapp/` into Tomcat's `webapps/selavu/` directory:
   ```powershell
   Copy-Item -Path "Selavu\src\main\webapp\*" -Destination "path/to/tomcat-10.1/webapps/selavu" -Recurse -Force
   ```

3. **Start Tomcat**:
   Start the Tomcat server:
   ```powershell
   # Windows
   cd path/to/tomcat-10.1/bin
   .\startup.bat
   ```

4. **Access the App**:
   Open your browser and navigate to:
   ```
   http://localhost:8080/selavu/homepage.html
   ```

## ⚙️ Database Schema (Auto-Created)

The application automatically creates the following relational schema in H2 database file (`~/selavu_db.mv.db`) if not found:

### Users Table (`selavu_users`)
* `uname` (VARCHAR(50), PRIMARY KEY)
* `email` (VARCHAR(100), UNIQUE, NOT NULL)
* `upass` (VARCHAR(100), NOT NULL)

### Expenses Table (`selavu_expenses`)
* `expense_id` (INT, GENERATED BY DEFAULT AS IDENTITY, PRIMARY KEY)
* `uname` (VARCHAR(50), FOREIGN KEY references `selavu_users.uname`)
* `amount` (DECIMAL(10,2), NOT NULL)
* `iname` (VARCHAR(100),NOT NULL)
* `qty` (VARCHAR(50))
* `category` (VARCHAR(50),NOT NULL)
* `pdate` (DATE, NOT NULL)
